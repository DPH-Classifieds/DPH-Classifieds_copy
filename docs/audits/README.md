# Audit evidence

This directory contains review artifacts that are safe to commit with the
application source:

- `AUDIT_REPORT.md` — consolidated static audit and source-backed findings.
- `audit_fixes.md` — remediation ledger, verification results, and remaining
  deployment gates.

The source PDF, screenshots, exported documents, original marketing media,
credentials, recovery codes, environment files, caches, and generated build
outputs remain local-only under the repository ignore rules. They must not be
added to GitHub.
